Forward Deployed Engineer at Navayuvak Entrepreneurs · founder of [Vigil](https://getvigil.in) · B.E. AI & Data Science, Mumbai (2027).

## Projects

- **[Vigil](https://getvigil.in)**: brand-reputation SaaS that asks ChatGPT, Gemini and Perplexity what they say about a brand and flags crises early. Solo build (Next.js, FastAPI, Supabase); code is private. Grew out of [NeuroChain](https://github.com/Tanmay-Ts/neurochain), top 5 of 5,000 teams at Mumbai Hacks 2025.
- **[The Tireless Hand](https://github.com/Tanmay-Ts/Tireless)**: an LLM agent injects realistic bugs into a drone flight cockpit, and a deterministic Playwright harness with no LLM calls in the test loop has to catch them. Zero false alarms; the bugs it missed are written up too.
- **[Highlight reel pipeline](https://github.com/Tanmay-Ts/Reel-MMA)**: turns raw MMA gym footage into 9:16 reels. Motion and audio heuristics find moments, GPT-4o vision scores them, ffmpeg renders, GitHub Actions runs it.
- **Execution Divergence Metric**: LLM evaluation paper on the gap between how well a model explains a rule and how well it follows it (900 preregistered instances, Llama 3.1 and Gemini 2.0 Flash). Under review at ACL Rolling Review.
